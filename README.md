# Flash-OPD: Fast On-Policy Distillation

Project page for **Flash-OPD**, which accelerates on-policy distillation by verifying each trajectory's reliability boundary during generation. On four teacher–student pairs it runs 2.2×–7.5× faster than full OPD while keeping or improving accuracy.

**Live page:** https://onedean.github.io/Flash-OPD/

The page is a single static `index.html` with no build step or external dependencies. It has an English/Chinese toggle in the top-right corner, or you can add `?lang=zh` to the URL. The paper, arXiv, and code links will be added on release.
